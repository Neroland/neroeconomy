# Bank Terminal

The Bank Terminal displays the balance synchronized from server data slots. Enter an online player
name or UUID and a positive amount; the server resolves the account, checks the still-open menu,
deduplicates the request, and performs one atomic Core currency transfer.

The Collect button delivers durable market proceeds and item claims. Using a Credit Chip on the block
redeems exactly one chip for the server-configured value after a successful deposit. The terminal has
no client-trusted balance, recipient, price, or mutation path.
